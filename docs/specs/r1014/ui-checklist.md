**规则**

- 任务只要改到下表"任务"列里出现的编号，就要把对应行做完；后端任务也一样，接口有了、页面没跟上，不算完成。
- 做完把"状态"改成 `完成 · {提交号}`；只做了后端写 `仅后端`；推迟写 `推迟 · 原因`。
- 页面数据只走 keel-server 接口；原型里写死的数字只是布局参考。
- 同一页的多维度信息用 tab，不上下堆叠。
