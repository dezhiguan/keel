# R3-5h 生成岗位的评测输入契约

## 目标

元智能体生成的岗位入口接受 `invoke.input.text` 中的自然语言，也接受 JSON 对象字符串。H2 已确认的 `spec-agent` 可见用例使用前者，现有生成入口仅调用 `json.loads`，所有用例都会在岗位逻辑执行前失败。

## 依赖与范围

- 依赖 R3-5、DF-5；不改跨语言契约和控制台字段。
- 修改 `agents/meta-agent/workflow.py` 的可信入口模板及对应的岗位交付测试。
- 自然语言包装成 `{"text": 原文}`，JSON 对象保持原样；JSON 数组等非对象输入拒绝。
- 不改变人审、隐藏考题、门禁或发布条件；现有 `DF-0002` 精确提交不会被静默替换。

## 界面对齐

`ui-checklist.md` 的 R3-5 对应任务详情展示保持现状；本修复不增加页面字段。

## 验收

- 生成入口用真实可见用例形状 `input.text: "一句自然语言"` 时调用 `execute({"text": ...}, ctx)`。
- JSON 对象字符串仍传原对象；数组仍返回参数错误。
- 只运行 meta-agent 对应的定向用例。
