# R1019 回归基线必须绑定当前已发布版本

正式验收时核对2pt回归门禁发现EvalJobs.baseline直接读取最近prod/DONE评测，不检查是否发布，也遗漏从dev实测后发布prod的版本。因此未发布的失败评分会污染下一轮基线，页面“prod当前版本”与实际不符。已有记忆ec8评测有1条未给具体工具名的质量失败，0.984375通过初始总分门禁，但其旧已发布dev实测基线没有被读取，不能作为回归规则正确性的证据。

修复：先选agent最新env=prod的release_record（含rollback，不能跳过最新记录取旧release），再按ci_run_url关联eval_run；仅当agent、image一致且结果complete/passed为true时使用其dimensions，来源env可为dev。没有关联平台评测的历史发布或提示词rollback保持无基线（界面—）；有关联却证据无效时拒绝启动该评测，不向更早发布或未发布评测回退。不同agent/镜像禁止误绑定。

验证真实PG：dev实测发布prod可成为基线；更晚未发布prod/DONE（包括未通过门禁）不改变基线；发布新证据才切换；最新无关联历史发布不能偷用更老证据；不完整/未通过或镜像不符的关联拒绝。SDK已有按标签2pt拒绝回归的测试保留。部署后再运行记忆完整51条验证，先前完整分数、发布记录及质量失败均保留审计，不能把重跑视为模型质量问题从未发生。
