# R1019 评测进度恢复

页面运行回归后刷新或离开再返回，后台 Job 仍 RUNNING，但页面显示没有评测记录，运行按钮可点且仅返回已有任务。截图 eval-running-not-restored.png，运行 ev_402403f519c94fd88cbff799b3dfe09f。

增加只读 GET /eval/{agent}/runs/active，返回当前 QUEUED/RUNNING 的 runId，没有任务时 null。沿用评测读取权限，不返回输入、密钥或用例。页面加载时恢复轮询；点击运行立即锁定按钮，离开或切换智能体时停止旧轮询，过期响应不能覆盖新智能体。保留最近完成结果展示。实际 Job 不重复启动。

验证：后端查询只取活跃任务；页面刷新恢复、切换隔离、重复点击锁定；部署后真实页面验证。

本地定向 Java 8 项通过，Postgres 集成 3 项因本机无 Docker 跳过；前端类型检查通过。CI 与部署后真实刷新验证仍待执行。

补充：智能体选择写入 URL 查询参数，刷新保留当前对象；旧 latest 请求的迟到结果不能覆盖刚完成的轮询结果。
