# R1019 配额拒绝未出现在账单/拒绝列表

页面实际RPM/TPM/并发拒绝后，「最近被拒绝的请求」仍显示点模拟请求，真实拒绝没有账单。Admission在账单生成前抛错，未留只含计量摘要的零费用记录。截图quota-denials-missing-ledger.png。

对有效Key的限流/预算拒绝记录FAILED、输入输出0、费用和预留0，同一个服务端requestId与traceId，routeVersion用rejected:已登记错误码表示执行前拒绝；不是厂商调用，也不能影响熔断。SDK保留429响应头requestId以准确关联零费用。页面显示网关配额/预算拒绝、模型未调用，其他失败继续显示模型和路由；不生成未知Key的身份记录，不记录用户原文或密钥。

验证账单0费用且不增加预算预留，SDK不重试429，错误请求ID可关联；线上拒绝后页面有真实记录。TPM文案明确按已结算用量限制后续请求。
