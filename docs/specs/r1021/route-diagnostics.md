# 路由试算与逻辑模型默认值

用户确认保留路由试算。普通操作只选择虚拟 Key，按其所属智能体同环境最新登记清单的 models.default 诊断；不存在登记配置时明确提示，允许高级模式手填请求模型名，不猜测第一个真实模型。请求模型既可为逻辑名，也可为实际模型，高级模式说明两者语义。

新增 POST /insight/route/diagnose 与薄网关 POST /admin/v1/route/diagnose；保留旧 preview 契约。结果展示已发布版本、环境、请求模型及来源、全部分流权重（包含灰度）、降级策略、各模型授权与熔断、最低输入限制和 Key 停用。诊断不随机选单个分支、不请求上游、不写账单；结果仅为当前配置诊断，不承诺预算/限流检查或将来请求必成功。

控制台显示加载、错误、完成时间；切换 Key/请求模型或路由发布后清除旧结果，过期响应不得覆盖新选择。高级选项提供逻辑名称与授权实际名称，并允许输入其他请求名验证错误。

个人助理在独立仓库删除 models.fallback，保留 chat-default，通过现有真实完整评测后发布 staging 新版本，不改提示词、工具权限、100元网关覆盖预算或 prod。

验证：全部分支/灰度与缺授权、断路器/停用、实际模型兼容与不发模型请求；同环境清单选择、UI构建/类型与生产页面试算；新助理镜像完整真实门禁及发布证据。

候选配置接口允许在默认模型不变时删除/清空应用fallback（权限只收窄），不改网关Key和Secret；仍拒绝添加或替换fallback及其他权限边界变更。
