# R1021 侧栏名称与说明

## 目标

按用户确认的十一项导航更新左侧模块名称，每项标题下显示简短说明。沿用现有深色主题、分组、图标、选中态和审批数量；模型网关放在工具与技能之前。观测分组顺序为提示词管理、测评中心、链路追踪，保留页面路由和既有业务入口。

| 路由 | 名称 | 说明 |
|---|---|---|
| /overview | 运行总览 | 运行状态与核心指标 |
| /agents | 智能体管理 | 配置、调试与发布 |
| /jobs | 智能体研发 | 从需求到交付 |
| /services | 基础服务 | 平台组件与共享能力 |
| /prompts | 提示词管理 | 版本管理与调试发布 |
| /eval | 测评中心 | 效果评测与质量把关 |
| /traces | 链路追踪 | 调用过程与异常定位 |
| /models | 模型网关 | 模型接入、路由与计费 |
| /tools | 工具与技能 | MCP 工具与 Skill 管理 |
| /approvals | 审批中心 | 人工审批与事项确认 |
| /audit | 审计中心 | 操作留痕与记录查询 |

## 范围

- `console/src/router/nav.ts`：统一维护标题、说明和顺序。
- `console/src/layouts/ConsoleLayout.vue`：显示上下两行文字，保证窄侧栏文字可读和独立滚动。
- `console/src/router/nav.test.ts`：更新既有导航顺序断言。
- 本 spec 和 `docs/specs/r1014/ui-checklist.md`：记录用户确认的原型差异和验证状态。

仅调整侧栏；不修改页面业务、接口和权限。以用户本次确认覆盖历史原型的侧栏名称与顺序。

## 验证

运行既有导航测试和控制台生产构建（包含 TypeScript 检查），检查 diff 与模型网关的实际分组顺序。

验证结果：既有导航测试 2/2 通过，控制台生产构建与 TypeScript 检查通过，`git diff --check` 通过。
