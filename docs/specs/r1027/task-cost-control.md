# 单任务成本控制实施与个人助理试点

依据 docs/design/Keel-智能体单任务成本控制能力方案-20261027.html 与个人智能助理成本优化试点方案-20261027.html。用户授权实现、提交、推送、部署后真实验收。不引入缓存，不改变临时上下文容量来制造收益。

## 实施边界

- 网关 PostgreSQL 保存任务及请求关联，原子准入覆盖多个副本/并发与后台调用。实际账单仍由 llm_spend 按 attemptId 记账，任务费用通过 requestId 关联账单计算，避免第二份结算账。
- 平台受信入口建立根任务、固定策略快照，签发绑定虚拟 Key 别名的随机任务票据；SDK 只透传票据，不允许从用户正文指定预算/owner/策略。票据不得进入模型、日志或可读报告。
- 平台配置按 platform / org / env / agent 解析；低层不能提高高层费用或尝试边界。任务材料规模可在策略范围内调整估算；observe/enforce 版本化，已有任务保留快照，当前权限/停用实时检查。
- 任务费用包括前台、后台、维护及所有失败/降级；未决调用保守预留，不因断流释放。共享维护费用按覆盖轮次分摊并保留关联，不把历史日恢复额伪装任务明细。
- Python 正式 SDK 自动传递上下文、禁用应用侧额外状态重试，并为缺少上游成本上下文的标准入口建立受服务身份限制的任务；不支持路径明确上报覆盖。Java/第三方路径须通过覆盖检查后才能启用强制控制，不能伪报支持。
- 助理复用公共机制，精简重复工具数据/规则，动态控制必要输出，记忆合并与调度按新内容及最大等待触发；更正撤回立即有效。保持权限、引用、原文保留与完整任务质量门禁。
- 生成模板/SDK与登记能力检查更新。增加只读任务费用/策略查询和受管理策略发布/回退，不向用户暴露网关管理凭据或任务票据。

## 顺序与可回退

1. 先契约/错误码与 PostgreSQL 迁移，再网关权威费用与预算、平台身份与策略，测试并部署兼容版本（旧入口仍可观测未覆盖）。
2. 正式发布 SDK，助理锁定新 wheel/hash，真实评测后部署候选并核对双副本版本；只在个人助理 staging 启用试点策略。
3. 对照设计逐项验收，保留账单/失败/尚未实现项。真实成本目标不能用调用次数或费用上界代替。30%为试点待验证目标，不是公共平台保证。
4. 观察/执行模式及业务优化分别回退；不清零未知预留、不删除失败证据、不降低门禁。

## 付费输出上界补充（2026-10-28）

供应商 `max_tokens` 可能不包含思考输出，不能只按可见回答估算。报价及实际路由复核必须应用真实 alias/purpose 的上游默认参数；明确关闭思考才使用回答上限，未知或开启思考保守额外预留模型输出容量；显式完整输出上限及多候选计费独立处理。不通过关闭思考降低报价。实际结算继续以供应商 usage 为准。

依据：[阿里云 Chat API 参数](https://help.aliyun.com/zh/model-studio/qwen-api-via-openai-chat-completions) 对 `max_tokens` / `max_completion_tokens` 的定义及最多 10 token 误差说明。其他供应商 / 多模态输入需要单独验证覆盖，不宣称任意第三方模型都已验证。

## 必须覆盖的测试

跨别名/owner/env、可信传播与票据不外泄；并发预算与请求去重；多次尝试/未知付费/晚结算；策略继承冲突、快照/回退/停用；前台与后台/共享维护费用守恒；新项目与旧SDK覆盖；助理事实更正/撤回/检索引用/长材料完整性；配对实际已结算费用、成功率、P95与后台收敛。既有测试/真实服务身份隔离继续通过。
