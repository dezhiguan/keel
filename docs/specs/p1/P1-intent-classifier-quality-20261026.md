# 慢分类独立质量与启用验收

本轮补齐设计第04节启用门槛与IR-24。实现位于独立keel-assistant仓库，平台接口、SDK版本及页面字段保持原契约，不新增远端/编排/写入权限。

固定120条核心样本（60开发、60留出）和20条来源边界样本，真实受管提示词、ctx.llm及官方SDK。先固定准确率、每类、资源来源、额外澄清、超时、费用与私有token门槛；保存所有初始失败，不改原100条正式业务门禁。分类只处理L1 unknown，显式规则/任务回执/Worker不额外分类。

先通过独立进程做组件评测，再提交主干、构建不可变应用镜像、核对双副本，按shadow→read_only验证真实USER请求。Secret仅修改本助理的模式与8秒超时，使用resourceVersion检查并保留其他配置。页面对照控制台原型的调用树/节点详情，读取intent.classify安全指标、关联generation提示词版本，以及真实intent.route/step，不把内部JSON放进用户token流。更新ui-checklist和原设计现状，历史未完成记录保留为历史。

正式prod标签、业务100门禁、远端/复杂编排、持久化审计及真实第二USER未完成项不因本专项通过而标记完成。
