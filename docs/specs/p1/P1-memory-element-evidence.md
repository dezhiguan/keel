# 要素检查的会话与长期记忆证据

## 问题与范围

个人智能助理通过平台 PG 历史维持多轮会话，但清单未声明 capabilities.memory。
现有要素检查将其显示为缺失，并拒绝用实际记录纠正结果。
修复仅涉及记忆要素的证据读取和详情展示，不改变智能体运行方式、记忆写入或发布门禁。

## 行为

- 保留现有 12 项及接口结构。记忆未验证时为未知，不列为缺失。
- 平台会话证据按智能体、环境、同一会话及同一用户隔离；只统计未过期消息。
  同一会话至少两条用户消息和一条助理消息才算多轮证据。
- 长期记忆只统计 user_memory 的 USER 层记录，不能把任务或经验记录算作个人长期记忆。
- 实际记忆记录可以证明记忆要素，无需先声明 capabilities.memory；其余要素规则不变。
- 会话和长期记忆分别显示证据状态。没有记录表述为暂无证据，不断言未接入。
- 记忆证据读本地数据库，不为此查询 Langfuse。运行证据不代替发布门禁。

## 验证

后端回归覆盖未声明但存在会话、仅长期记录、无记录，以及环境与过期条件；
前端覆盖已验证记忆的分层说明和未知态。执行后端定向测试、前端测试及类型检查。
发布后核对线上个人助理 elements 接口和静态前端版本。
