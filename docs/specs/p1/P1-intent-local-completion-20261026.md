# 本地意图路由补齐（2026-10-26）

本轮补齐：独立 IntentPacket / RoutingContext / RoutePlan 的跨语言契约、动作参数及槽位来源校验；保留现有路由元数据的 keel/v1 兼容性；L1 识别与 L2 策略规划分离，统一入口实际消费本地计划和步骤，记录 request/plan/step/policy 及输入输出引用；本地条件、依赖、independent_only/require_all、拒绝和澄清；同一助理队列仍经过原任务授权/去重/回执/fence。计划不能授予权限，执行前仍复验原票据、对象和环境。

慢分类模块可开发、验证并提供明确 off/shadow/read-only 模式：仅规则未确定时使用 ctx.llm 的受控结构化输出，禁止业务工具及用户 token，绑定最小上下文、独立超时、调用上限、降级及代价记录。off 为部署默认；没有目标网关/模型真实兼容及独立质量证据不得启用 live 路由。不能用“local_slow”标签冒充分类器或通用编排。

路由审计补齐计划/步骤/结果事件和白名单字段、拒绝时机、高风险写前同步失败关闭的既有约束，以及 trace 展示。恢复此前被后续 main 部署覆盖的审计与取消保护，并将验证后的代码纳入正常主干部署，避免长期悬空候选。审计数据库/MQ真实持久化不在本轮“已具备条件”的声明内；只能记录真实交付边界，不能以 HTTP204、本地容器文件或 Trace 冒充闭环。

不启用远端、跨员工队列、并行、复杂重规划或新管理动作；契约可保留可选引用字段，规划器必须拒绝当前策略不可执行的 remote/approval，不能借枚举扩权。保持主分支已合入的110元预算、能力声明、历史性能、AskDB身份和评测显示修复；不降低既有完整业务发布门禁。
