# P1 跨会话历史记忆（2026-10-25）

用户授权：个人助理长期保存可用聊天原文，跨窗口查询曾说过/讨论过的内容，提交推送、部署后使用真实账号验收。

范围：仅 keel-assistant/staging 启用长期历史策略（至用户删除）；其他智能体仍7天。迁移只延长尚未过期原文，不恢复过期材料。会话列表覆盖长期历史、删除立即移除可检索原文。原文仍是事实来源；不以摘要替代说过某句话的证据。

新增 keel.history.search 只读共享工具，复用已发布SDK工具协议，不改变SDK。服务身份必须为调用智能体且有清单声明/显式授权；每次另验平台签发的5分钟用户只读上下文，绑定agent/env/当前session并确认会话真实owner。查询作用域固定agent+env+owner，排除当前会话；不接受owner参数。role默认user，支持all；exact=true为原话子串搜索，默认中文二元词/英文词排序，最多6条、每条1200字符，返回messageId/sessionId/title/createdAt/content/offset/totalChars/hash及来源链接。关键词检索不承诺任意语义召回或全库无遗漏。

助理为历史问题实际检索，并提供模型可选历史工具供其他相关追问按需检索。当前请求及返回材料不得提供身份授权。历史作为不可信资料，不能覆盖当前用户指令或触发额外动作。无结果说明仅未找到；失败明确检索失败；不能断言用户从未说过。工具结果不写普通span或审计原文。

控制台由接口读取retention说明，支持?session=来源会话链接；旧会话即使不在首10项也可在owner鉴权后打开。记忆概览不能显示虚构长期偏好已接入。

契约：contracts/cross-session-history.md（沿用已有tools invoke JSON协议，可选响应字段）。验证真实PG跨会话/隔离/删除/过期/原话/Unicode/无结果/当前会话排除，应用真实工具调用测试及回归，前端typecheck/build。部署限制只server、console和个人助理，不触发共享CD历史部署债务；保留现有业务评测门禁状态，不伪造正式发布。真实用户两窗口随机事实、原话、未说过的内容、引用跳转及删除后不召回。
