修复内容
1. 关键词历史命中附带同一用户/助理/环境/会话中紧邻的助理回复，明确角色及原始消息信息，总摘录预算仍不超过1200字符；精确用户原话检索不扩展助理内容。
2. 历史路径只提供历史工具，最多2轮补查、3个模型步骤；最终阶段明确禁止新增工具调用，保留错误与真实来源，不扩大权限或编造答案。
3. 正式SDK增加interactive调用purpose，网关仅对个人助理staging、指定实际模型的交互调用关闭思考；memory和后台analysis各自配置保留。
4. SDK在ASGI生命周期内复用有界HTTP传输连接池，每个请求的授权、Cookie与trace独立；单请求取消/关闭不会关闭共享连接池，应用退出释放资源。
5. 对话入口复用本次请求已校验的登记快照，减少重复读取；新请求继续检查下线状态，未缓存用户权限。
同步事实一致性、10000 token输入上限、预算、副本数和CPU/内存限制不变。
