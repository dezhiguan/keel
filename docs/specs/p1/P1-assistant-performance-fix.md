5. 对话入口一次准备取得登记快照，签发用户上下文、异步转发复用本次快照，消除同一请求重复构造完整详情；每个新请求仍重新核查，不缓存权限和下线状态。
6. 保留同步会话事实一致性与10000 token上限；优化后比较多轮端到端首字，不删除维护步骤。
