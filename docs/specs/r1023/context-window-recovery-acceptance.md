## 验收范围与限制

真实模型验证通过Pod的正式/v1/invoke协议，使用平台原会话历史和同一身份/会话范围；未向平台PG注入测试聊天消息。控制台旧登录凭据已失效（401，刷新503），未完成登录后的浏览器端到端点击验收。

初次长历史压缩约51秒，后续复用本次摘要的追问约5秒；摘要工作最多4次、单次25秒、每轮累计60秒，失败退回可容纳的近期完整轮次，不覆盖原文、不推进持久化摘要游标。平台只提供最近128条历史，窗口外历史搜索及跨会话长期记忆属于后续工作；存储仍沿用7天保留期。
