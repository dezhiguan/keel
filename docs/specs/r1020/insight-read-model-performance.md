# R1020 调用链路与运行总览读取模型

## 问题和证据
2026-10-20 使用登录账号实测：总览 3910ms，链路 3569ms 后 HTTP429。链路每次缓存失效后拉两组全窗 observation（每组最多10页）、组装全部详情后内存分页；总览冷启动等待 roots、scores、experiments，重复全历史账单，前端 Promise.allSettled 又把研发任务加载加入首屏屏障。30秒进程缓存无法跨副本共享，重启丢失。

## 行为
- 链路列表只读 PostgreSQL 索引和本地运行状态，数据库筛选后计数/分页。完整节点和输入输出仍在点击详情时读取。索引只保存精简 observation 与用户问题摘要，不保存生成节点正文或系统提示词。
- 单个数据库租约协调两副本后台同步：每次一个 v2 observations 游标页，固定时间边界、持久化游标、幂等 observation id；先根摘要再语义子节点。初次回填30天（覆盖总览30天窗口），之后最近1小时重叠同步，每30分钟重新核对7天，覆盖延迟上报和旧运行更新。失败不推进游标；429尊重 Retry-After；每次读取有20秒超时，正常页间至少8秒。
- 每页更新受影响 trace 的摘要，初次尚未扫描完成明确显示“历史同步中”，total 是当前已索引数，不宣称全量。完整扫描后标记覆盖范围；本地 invoke 与挂起运行合并去重，筛选在分页前完成。最新挂起/恢复以本地运行表为准。
- 总览完整响应按环境和窗口持久化共享，60秒过期异步刷新；冷启动立即返回注册/审批数据，外部指标为空并标记同步中，不阻塞HTTP。请求重试和失败保留上次成功响应；不同窗口不混用缓存。后台汇总账单复用一份共享快照，避免各环境、各窗口重复翻全历史；总览不查询模型页面专用延迟采样。
- 两页新增可选 dataStatus（updatedAt/state/complete/from/to），状态 loading/ready/stale/unavailable。页面独立呈现同步提示，冷启动短间隔有限轮询，正常30秒刷新；切换/离开取消请求、清理轮询，失败可重试。总览研发任务独立加载，不阻塞指标。
- 成本只用网关结算 costCny，待计费保留为空/待计费；不改评测门禁，不把失败伪装为0。

## 验证
数据库真实 PostgreSQL 测试租约互斥/过期接管、游标失败不推进、幂等增量、子节点跨页合并、环境/任务/状态筛选后分页、挂起恢复、缓存重启复用与旧写者隔离。HTTP桩测试单页和字段/超时、429。前端检查取消、独立加载与同步状态。CI/CD成功后账号页面实测24h/7d、筛选/翻页、总览窗口及外部失败时可读性，记录真实耗时和口径限制。
