# 技能注册表导航与分页

技能 tab 在「注册表」旁把每个技能名做成 chip。技能一多会横向拥挤，也和工具「列表点进详情」不一致。

改动只动控制台 `ToolRegistry`：

- tab 文案改为「工具（tool）」「技能（skill）」，与设计里 tool / skill 定义对齐。
- 去掉技能名 chip；技能 tab 默认只显示注册表；点行打开详情，标题区用「技能 › {name}」和返回注册表。
- 注册表用现有 `Pager`，默认每页 10 条，可选 10 / 20 / 50 / 100。`GET /skills` 仍一次返回全部，页面内切片；列表长度变化导致当前页为空时回到第 1 页。
- 带 `?skill=` 的详情深链、发布后进入详情、工具 tab 与技能详情内容不改。
