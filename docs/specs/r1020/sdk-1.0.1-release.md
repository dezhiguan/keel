# SDK 1.0.1 兼容发布

用户已授权发布兼容补丁版，以支持独立个人助理的真实聊天验收。基于已存在的 keel/v1 实现发布，不改共享模型路由、预算或其他智能体凭证。

发布能力包括真实模型 SSE、空工具列表、结构化会话历史和受管理提示词版本元数据。先验证 Python SDK、契约、模板与正式 wheel；使用既有 sdk-v1.* 发布流程，不覆盖 1.0.0。个人助理只从正式 Release 安装并锁定新版本与哈希。

全量检查发现测试夹具未同步流式协议及环境变量泄漏：standalone 测试网关仍返回非流式 JSON；两个提示词测试直接写 os.environ 导致随后模板继承失效的 Langfuse 主机。修复测试夹具和隔离，不降低断言。标准 manifest 端点改为返回实际安装的 SDK 元数据版本，以便追溯发布制品；字段和协议不变。

另外同步两处旧测试假设：模型替身接受现有 prompt 参数，断言循环开始 step 后的终止 error；工单模板从末尾解析终止事件，不把先行护栏事件当 suspend。保留步骤上限、审批恢复与检查点的业务断言。

不改控制台页面，不新增跨语言字段。验证并保留测试结果、提交号、发布流水线和正式 wheel 哈希。
