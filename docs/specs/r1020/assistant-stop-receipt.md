# R1021-assistant-stop-receipt：停止接收与取消任务分开

MVP0.3真实任务可在聊天响应结束后继续执行。当前AgentDebug在浏览器AbortController停止SSE后显示“这次调用已取消”，不能证明模型或持久化后台任务已取消，易造成错误完成/取消认知。

仅对keel-assistant/staging的现有聊天页，停止接收回复后的气泡改为“已停止接收本次回复；后台执行未确认停止。”，事件提示已创建任务需通过对话查询或取消。继续使用原停止按钮、统一聊天页和abort行为，不新增工作模式、管理操作或任务状态迁移。真实取消仍须由受控任务工具返回状态，不能把接收停止显示成cancelled。

原型对齐：已对照docs/console/Keel-控制台前端-20261014.html的调试入口；原型尚未覆盖现有AgentDebug聊天“停止接收”状态，本spec补充该控件文案约束，沿用现有布局。ui-checklist增加本任务行。契约结构、SDK、Worker和数据库不变。单独提交、CI构建；当前个人助理正式评测结束后再部署平台控制台，避免平台滚动干扰冻结评测。真实USER在原页面启动一条隔离测试聊天并停止接收，核对新提示、无任务已取消承诺，并保存截图/请求证据。原始失败和其他工作不覆盖。
