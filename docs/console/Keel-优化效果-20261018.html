模型与成本

薄网关 keel-llm · 2 副本提案
要做拆出「渠道」= 厂商 + 账号/业务空间 + 密钥 + 地址，一个模型挂多个渠道；渠道配厂商 RPM（每分钟请求数）/ TPM（每分钟 Token 数）作天花板，网关 Redis 按渠道计数，超出在网关拒绝；按环境绑定渠道；熔断按渠道计，同一上游地址的不同账号互不影响；厂商 429 改打同模型另一渠道（最多一次，和换模型共用额度；流式未开始输出才换；网关自身份额 429 不换；尊重 Retry-After），需先改技术文档和 external-apis.mdc；Batch 单独通道不占实时份额。百炼子业务空间与 Batch 接口先实测。
